# 面向角色的战斗策略编辑器

一个用来编写、修改和维护适用于 BetterGI 的自动战斗功能的**JSON 战斗策略**的本地网页工具。这个工具的最终目标是用于创建包含全部角色的 JSON 战斗策略，同时尽可能简化 JSON 战斗策略的编辑。

## 功能介绍

面向角色的战斗策略编辑器是一个**离线单文件网页**：双击打开就能用，不需要安装、不需要服务器、不需要联网，编辑过程中产生的数据全部只保存于本地。
它的作用是将编辑 JSON 策略简化为「选择角色、构建动作、设置条件」这样一个简单的流程，你只需要聚焦于每个动作的指令与条件即可，无需考虑手敲 JSON 策略时需要面对的各种繁文缛节。

编辑器最主要的几个能力：

* **以角色为单位编辑动作**。左侧列出全部角色，选中一个角色就能看到它已有的动作，并为它新增动作。你不需要考虑如何为动作分配编号，也无需自己去记任何动作的编号。
* **自动分配编号（index）**。每条动作的编号由「动作类型 + 元素 + 角色 + 同类型序号」拼出来，全部由编辑器算好，并且在你改动动作类型、复制动作、重排编号时自动同步。
* **自动推导优先级（priority）**。为动作添加「其他触发条件」时，你只需要选择这条条件**优先于 / 次于**哪一类动作（的基础条件），具体数值由编辑器推导，不需要自己算数字。
* **动作指令与条件表达式的快捷编辑**。提供动作指令和条件函数的快捷插入、参数选择、中文释义、运算顺序预览，以及输入时的实时校验（未知指令或函数、参数个数或类型、中文符号等问题会当场提示）。
* **队友条件与命座要求**。可以直接设置「必须有 / 必须没有哪些队友」，也可以为一条动作设置命座要求与启用 / 停用开关，让同一个角色在不同队伍、不同命座下使用不同的手法。
* **优先级预览**。按 BetterGI 的真实判定逻辑把所有触发条件展开、排序，直观检查「谁先谁后」是否符合预期，并支持用模拟队伍过滤，针对特定队伍检查。
* **导入 / 导出 / 合并 / 本地草稿**。可以导入既有策略继续编辑，可以把当前编辑内容导出成 JSON 放进 BetterGI 使用，可以把另一份策略有选择地合并进来，编辑过程中的内容也会自动存成浏览器本地草稿。

而该编辑器最关键的特点是：通过**以角色为单位归档动作**、**基于相对次序设置优先级**、**优先级与条件的集中预览**等功能的组合，避免了在战斗策略规模过大时，
由于同一角色的动作散落于整个动作节点数组各处、同一动作的各优先级条目的相对位置难以确定等问题，所导致的战斗策略复杂性爆炸。

因此，该编辑器**适合编辑包含角色数量众多的，乃至于包含全部角色的超大型战斗策略**，并确保这种超大规模的策略可以为任意角色充分适配手法不同的多种配队。

需要注意的是，本编辑器**只负责战斗策略的编辑**，战斗策略的执行、自动战斗的设置、战斗结束检测等均依赖于BetterGI本体设置或执行。

## 使用方法

1. 若要获取本编辑器，直接把整个仓库里的源码下载下来即可。
2. 打开 `JsonCombatStrategyEditor` 文件夹，双击其中的 `面向角色的JSON战斗策略编辑器.html`即可使用。推荐使用 Chrome 或 Edge 打开。
3. 打开后，顶部有三个页签：「策略信息 / 导入导出」、「动作编辑」、「优先级预览」。第一次使用时，建议先去「策略信息 / 导入导出」页导入一份既有策略或新建一份带兜底动作的策略，再到「动作编辑」页开始编辑动作。
4. 如果您还不清楚 JSON 战斗策略是什么，或者对如何设计战斗策略毫无头绪，请查看 **[JSON战斗策略入门指南](JSON战斗策略入门指南.md)**；它同时也是一份「从零做出一份能跑的策略」的完整流程介绍。
5. 如果您对本编辑器的具体操作方法存在任何疑问，随时可以查看 **[编辑器使用说明](编辑器使用说明.md)** 了解具体操作。
6. 将该编辑器中导出的 `.json` 策略复制到 BetterGI 的 `User\AutoFight\` 文件夹下，或置于其子文件夹下，即可在 BetterGI 中选择使用该策略。

> 建议的阅读顺序：先看本文件了解编辑器能做什么 → 再看《JSON战斗策略入门指南》了解思路 → 动手时对照《编辑器使用说明》查具体操作。

## 其他

* 该编辑器使用了源自 [BetterGI](https://github.com/babalae/better-genshin-impact) 的角色信息。
* `JSON战斗策略格式规范.md` 是作者设计本编辑器的主要参考资料，可作为理解 JSON 策略底层执行逻辑的重要参考。
* 该编辑器完全是作者通过 *"vibe coding"* 许愿出来的，作者缺乏对网页源代码的精确控制能力，编辑器中难免存在一些 BUG 和冗余注释。
* 该编辑器处于早期预览状态，随时有可能发生破坏性重构。
* 若BGI新增支持角色后本编辑器未及时更新，您可以让 Agent 使用 `JsonCombatStrategyEditor/tools/gen_avatars.mjs` 添加新角色的信息。
* 编辑器的星级筛选尚不可用，因为作者暂时没有搜索到现成的逐角色星级表，作者也懒得花时间整理角色星级表。如需使用星级筛选功能，请自行录入相关信息。
* 您可以通过 issue 反馈该编辑器的问题，或者直接在 v12 群联系作者反馈问题。，

## 关于 Agent 辅助生成战斗策略

本编辑器的源代码和测试工具已完整提供，理论上 Agent 可以直接使用这些工具生成符合本编辑器格式的策略。
但是，由 AI 生成的战斗策略，已经无数次被证明是**完全不可用**的！已经有一些群友亲自证明了， Agent 写的战斗策略还没有他（她）自己脸滚键盘写得好。

目前，针对 AI 始终无法生成可用的战斗策略的问题，所进行的相关研究和分析，指向了如下两个原因：

1. Agent 缺乏对原神中角色基础数据和天赋信息的原始数据的了解，使其无法正确理解每个角色的基本战斗特性。作为替代的，被人反复咀嚼过的二手信息，往往严重失真，无法反推出正确的角色战斗特性。
2. 缺少类似于在编程中使用的自动测试工具，导致 Agent 根本无法了解自己编写的战斗策略的效果，甚至无法理解作为参考的战斗策略是如何运行的。**执行效果全靠猜，能写得对才见鬼了呢！**

当然，以上两个原因绝非全部原因，但一定是最主要的原因。针对以上两个主要原因，解决方法也是显而易见的，那就是提供相应的信息和工具，虽然这件事此前从未有人尝试过。

目前，我们可以认为，**要让 Agent 写出能用的战斗策略，至少需要以下的工具和信息**：

- **战斗策略编辑器**。本编辑器就是一种战斗策略编辑器。 Agent 需要一个工具去检查和规范它自己输出的战斗策略，避免策略无法运行或出现非常明显的低级错误。
- **战斗策略转译为战斗模拟器语句的工具**。这种工具负责将战斗策略与预设的模拟参数、队伍配置和敌人配置结合起来，转译成可在战斗模拟器中使用的模拟条件语句。
- **适用于原神的战斗模拟器**。 gcsim 或类似的蒙特卡洛战斗模拟器，可以作为一种自动测试工具，根据上述转译工具输出的模拟条件语句运行上千次模拟战斗，以提供详细的战斗数据和具体战斗中的角色行动数据。
- **原始的角色天赋信息和角色、圣遗物、武器的基本数据**。这些未经修饰的原始数据，才是 Agent 理解原神战斗机制，设计战斗策略的可靠基础。同时，这些数据也可以用于辅助解读战斗模拟器中输出的结果。

尽管战斗模拟器并不能完美的还原 BGI 自动战斗的实际效果，但只要转译工具和模拟器设计得当，对角色战斗行动的模拟误差应该在可接受的范围内。

如果您希望利用 Agent 生成或修改 JSON 战斗策略，**请务必为您的 Agent 配齐上述工具和信息**。
如果您不具备为 Agent 配齐上述工具和信息的能力，就意味着您没有可能让 Agent 生成可用的战斗策略，请尽早放弃。

当 Agent 收到生成或修改 JSON 战斗策略的请求时，**请务必检查上述工具和信息是否齐备**。
如果缺少上述信息或工具中的任意一项，**请立即停止编写战斗策略，并索要相关信息和工具**，直到相关信息和工具齐备后才可以继续编辑战斗策略。
